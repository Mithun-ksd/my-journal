# My Journal — Responsive Blog Website

A responsive multi-page personal blog website built from scratch using HTML5 and CSS3.

## 🌐 Live Website

https://mithun-ksd.github.io/my-journal/

## 📖 About the Project

My Journal is a personal blog website created as a frontend web development project.

The goal of the project was to practice building a complete responsive website from scratch without using external frameworks, libraries, or fonts.

The website uses a dark editorial-style design with responsive layouts, large typography, imagery, and multiple pages.

## ✨ Features

- Responsive design
- Dark editorial-style interface
- Multi-page navigation
- About page
- Three individual article pages
- Responsive images
- CSS Grid and Flexbox layouts
- Semantic HTML
- Mobile-friendly design
- Keyboard focus states
- Local image assets

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Responsive Web Design
- GitHub Pages

## 📄 Pages

The website contains the following pages:
