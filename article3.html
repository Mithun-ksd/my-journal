BUILDING

Learning by Building Things

October 1, 2026

Tutorials can teach you the basics, but building something of your own forces you to actually use them.

When learning web development, it is easy to spend hours watching tutorials and reading documentation. There is always another video to watch and another concept to understand.

But at some point, you need to close the tutorial and start building.

Problems Become Lessons

When you build something yourself, things will eventually break. A layout won't look right. An image won't load. A link might lead to the wrong page.

These problems can feel frustrating, but they are also opportunities to understand how the code actually works.

Building Creates Questions

One of the best things about building projects is that they naturally create questions. You might suddenly wonder why a grid behaves differently on mobile or why two elements aren't aligned.

Those questions give you a reason to learn. Instead of learning something simply because a tutorial told you to, you are learning because you need it.

Make Something Real

This blog is one of my first projects. It isn't perfect, and it doesn't need to be.

The important thing is that it exists. Every page, every layout problem, and every small improvement becomes part of the learning process.

The best way to learn how to build things is to start building.
