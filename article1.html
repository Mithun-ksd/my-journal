How I Started Learning Web Development

October 3, 2026

The lessons I learned while building my first website.

Starting web development can feel overwhelming. There are so many technologies, tools, languages, and concepts that it can be difficult to know where to begin.

I decided to start with the basics: HTML and CSS. Instead of trying to learn everything at once, I wanted to understand how websites were actually built.

Starting with HTML

HTML was the first piece of the puzzle. It taught me that a webpage isn't just something that appears on a screen. Underneath the design is a structure made up of headings, paragraphs, images, links, sections, and other elements.

Once I started thinking about a webpage as a collection of structured elements, the whole process became much easier to understand.

Learning CSS

After understanding the structure, I started learning CSS. CSS is where things started becoming visual. I could change colors, spacing, sizes, layouts, borders, and images.

This was also where I started learning about responsive design and how a website needs to adapt to different screen sizes.

Learning by Building

One of the biggest lessons I've learned is that building something is often more useful than simply watching tutorials.

When something breaks, you have a reason to investigate it. When something works, you begin to understand why it works.

This website itself is part of that learning process.
